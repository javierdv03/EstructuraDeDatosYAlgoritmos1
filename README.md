# Estructura de Datos y Algoritmos I (EDA)
## Universidad de Almería
## Grado en Ingeniería Informática

Repositorio oficial con las prácticas, implementaciones de estructuras de datos y resolución de algoritmos desarrolladas durante la asignatura.

## Tecnologías y Requisitos
* **Lenguaje:** Java (Versión 17 o superior recomendada)
* **IDE recomendado:** IntelliJ IDEA / Eclipse / VS Code
* **Gestor de dependencias:** Maven

---

## Contenido del Repositorio
El proyecto está estructurado en diferentes módulos o paquetes orientados al estudio y aplicación de las estructuras de datos fundamentales:

* **`src/`**: Código fuente principal de las implementaciones.
  * *Ejemplos comunes:* Listas enlazadas, pilas (Stacks), colas (Queues), árboles binarios, tablas hash, algoritmos de ordenación y búsqueda.
* **`test/`** Pruebas unitarias para validar el correcto funcionamiento de las estructuras.
